- **Hook Graphify:** `core.hooksPath` = `.githooks` berlaku juga di worktree. Setiap `git commit` memperbarui dan ikut meng-commit `graphify-out/graph.json`, `graph.html`, `GRAPH_REPORT.md`, dan `manifest.json`; itu diharapkan dan tidak dihitung pelanggaran ownership. Jangan jalankan `graphify update` atau `/graphify` sendiri, jangan edit `graphify-out/` dengan tangan, dan jangan memakai `--no-verify`. Bila hook gagal, perbaiki penyebab yang dilaporkan lalu ulangi commit. Sesudah `git merge main` di worktree yang benar benar menggabungkan commit baru (bukan `Already up to date`), baik ada konflik `graphify-out/` maupun tidak, ambil keempat file graf dari satu sisi: `git checkout main -- graphify-out && git add graphify-out`, lalu `git commit`. Hook lalu melihat sumber branch yang belum tercatat dan membuat ulang graf. Jangan memakai `git checkout --theirs -- graphify-out`: itu hanya mengganti file yang konflik, sehingga `manifest.json` hasil gabungan otomatis membuat hook mencetak `staged sources unchanged` dan graf tertinggal. Bila `git merge main` mencetak `Already up to date`, jangan menyentuh `graphify-out/`: mengambil graf dari `main` tanpa merge membuang node commit branch. Lead melakukan hal yang sama saat merge ke `main` (`git checkout HEAD -- graphify-out`).
